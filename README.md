### About

I build full-stack, data-driven products end to end, from clean interfaces on the front to solid systems underneath. Increasingly, that includes systems that operate with less manual oversight.

- Currently focused on AI-assisted development, data science, and DSA, with an emphasis on understanding the systems deeply rather than just using them.
- Have explored automation tooling, AI agents, and applied machine learning through independent projects.
- Prioritize practical impact over polish. I'm more interested in how a system holds up under real usage than how it performs in a demo.
- Enjoy participating in hackathons and technical events, both for the challenge and the people I meet along the way.
